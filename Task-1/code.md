# Personal Portfolio Website

## About the Project
This is a Personal Portfolio Website developed using **HTML5 and CSS3** as part of a Web Development Activity-Based Learning project. The website showcases my personal profile, educational qualifications, technical skills, projects, and contact information in a simple and attractive layout.

## Features
- **Home Section:** Displays my name, profile image, and professional introduction.
- **About Me:** Provides a brief introduction about myself.
- **Skills:** Showcases my technical and personal skills.
- **Education:** Displays my academic qualifications.
- **Projects:** Highlights my projects, including Healthcare Portal, Business Website, and Landing Page.
- **Contact:** Provides my email, phone number, and location.
- **Navigation Bar:** Allows users to navigate between different sections easily.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox

## Project Objective
The main objective of this project is to develop a personal portfolio website to showcase my skills, educational background, and projects while gaining practical knowledge of HTML and CSS.

## Learning Outcomes
- Learned how to structure webpages using HTML.
- Gained practical knowledge of CSS styling.
- Understood Flexbox layouts and alignment.
- Learned how to create navigation links.
- Improved webpage design and layout skills.
